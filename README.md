# Chess
A chess tournament manager.

Round-robin, Swiss, and knockout tournaments can be managed from their leaderboard. Use New Round to generate pairings and Score Round to record results. Round-robin schedules are generated for the full tournament; Swiss tournaments ask for the round count once and create pairings one round at a time, balancing White/Black assignments for individual players; knockout brackets advance winners as results are entered. The leaderboard's settings page lets you select and drag to order tiebreak methods available for the tournament type. Team score entry lets you select a team and records games between matching player positions.
