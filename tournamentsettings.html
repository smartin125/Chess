Tiebreaks

Selection: Check an option to use it when two or more players have the same score.

Priority: Drag selected options to put the strongest tiebreak first. Tiebreaks are applied from top to bottom until players are separated.

If the full tiebreak order still leaves a tie, player names are used to make the final ordering stable.

Select tiebreaks and drag to change the application order
